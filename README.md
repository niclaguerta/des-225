# Match the Silhouette

Website for a playful DES 225 installation: visitors are encouraged to match the silhouettes on the wall.

Currently a **Coming Soon** page.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Fullscreen

Click the button in the bottom-right corner or press **F**. Press **Esc** to exit. While fullscreen, the button and cursor hide after a few seconds of no movement.

## Files

- `index.html` — page markup
- `style.css` — styles
- `script.js` — fullscreen toggle
- `assets/background.webp` — background artwork
